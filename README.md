### 🚀 Featured Projects

<details>
<summary><b>🗞️ FactFix — AI-Powered Fake News Detection Platform</b></summary>
<br/>

A full-stack AI application that analyzes news articles in real time, cross-references credible sources, and flags misinformation using LLM-based reasoning — deployed and hardened for production traffic.

| Category | Details |
|---|---|
| **Stack** | Next.js, Groq (Llama 3.3 70B), Supabase, NewsAPI, GNews, Framer Motion, Vercel |
| **Scale** | Multi-source aggregation across NewsAPI + GNews with real-time inference |
| **Performance** | Skeleton loading states, optimized client-side rendering, mobile-first responsive layout |
| **Security** | Upstash Redis rate limiting, auth-gated export endpoints, server-side session validation |
| **Impact** | Resolved critical production data-isolation bug (cross-user article visibility) via session-safe architecture redesign |

FactFix was engineered entirely on free-tier infrastructure while maintaining production-grade reliability — including a research-agent automation layer built with n8n, Groq, and Serper.dev for continuous source verification.

</details>

<details>

| Category | Details |
|---|---|
| **Stack** | Python, Streamlit, Plotly, Pandas, Scikit-learn |
| **Scale** | Multi-factor risk scoring with interactive visual breakdowns |
| **Performance** | Real-time chart re-rendering with minimal recompute overhead |
| **Security** | Input validation across all prediction parameters |
| **Impact** | Delivered a recruiter-ready, visually distinctive dashboard demonstrating applied ML + UI design |

Focused on translating raw predictive output into an intuitive risk-summary experience through custom Plotly visualizations and refined UI states.

</details>

<details>
<summary><b>🚗 ObstacleIQ — Autonomous Vehicle Obstacle Detection System</b></summary>
<br/>

A two-generation computer vision system for real-time obstacle detection and driving-decision inference, evolving from a video-pipeline architecture to a lightweight cloud-native design.

| Category | Details |
|---|---|
| **Stack** | YOLOv8, Streamlit-WebRTC, Gemini API, JavaScript Rule Engine |
| **Scale** | Real-time video inference with TURN-server-backed WebRTC streaming |
| **Performance** | Migrated to a single-file HTML architecture for lower-latency cloud inference |
| **Security** | Deterministic rule-engine overrides (AVOID / PUSH / ROLL) to prevent unreliable model decisions |
| **Impact** | Solved cloud-deployment reliability issues inherent to real-time CV pipelines |

Architecture 2 replaced a heavier YOLOv8 + WebRTC pipeline with a Gemini-powered single-file app layered with a JS decision-safety engine — a deliberate trade of raw CV precision for deployment robustness.

</details>
